SkyCast

SkyCast is a weather forecasting app built with React Native that lets you check the weather for any city around the world.

Features

    View current weather for any city.

    Search for cities and view their weather.

    Displays weather conditions like "Sunny" or "Cloudy."

Technologies

    React Native for building the app.

    Redux for state management.

    Axios for making API requests.

    OpenWeather API for weather data.

Setup

    Clone the repository: git clone https://github.com/Sam365x7/SkyCast.git
    Navigate to the project folder: cd SkyCast
    Install dependencies: npm install
    Run the app on an emulator or device:
        For Android: npx react-native run-android
        For iOS: npx react-native run-ios
